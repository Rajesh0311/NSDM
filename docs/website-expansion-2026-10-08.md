# Website expansion · 8 October 2026

## Preservation contract

NSDM remains an independent decision-systems research programme. Neuromarketing is an application lane, not its origin. Existing publications, supplements, drafts, benchmark results and limitations remain intact.

The main navigation, header, logo, typeface, palette, stylesheets, shared JavaScript, existing hero and publication downloads are unchanged. Existing page order is retained; contextual sections and links introduce the expanded research direction.

## Added routes

- `architecture.html`: human purposes, decision/behavioural science, models, NSDM boundaries, execution evidence and accelerated infrastructure. ACE is a cross-cutting engineering programme.
- `evidence.html`: proposed C1–C4 checks, optimization admission, Gate 0 and distinct evidence readiness.
- `frontier.html`: bounded AGI/superintelligence scenarios; no arrival forecast, demonstrated capability or solved-alignment claim.

## Visual provenance

- `accountable-intelligence-architecture.svg`: authored vector diagram of research responsibilities, with accessible title/description.
- `optimization-admissibility.svg`: authored vector diagram of proposed evidence checks, with accessible title/description.
- `frontier-infrastructure-concept.webp`: AI-generated editorial concept, explicitly labelled on the page. It is not a hardware photograph or product depiction. Converted from the generated PNG to WebP for delivery; approximately 164 KiB.

New assets use the existing warm off-white, ink, teal and amber palette. Existing brand artwork stays intact.

## Verification

Run `python scripts/check_website_expansion.py` and `git diff --check`.

The preservation check validates new internal links and fragments, JSON-LD, SVG/XML, navigation and inline styles, download targets, the original research body and byte-for-byte integrity of all existing assets and manuscripts.

Local browser preview timed out. Responsive visual review remains outstanding before release; static validation is not a substitute for browser QA. No website deployment tool is available in this session, although AGENTS.md names `build_and_deploy_html_project`.

## Research scope

ACE Gate 1 is linked to its versioned CPU evidence, not presented as GPU/TPU/cloud validation. Conservation harnesses remain proposed. Topology simulation is specified with feasibility pending, not a physical network benchmark. External release defects are not described as independently reproduced local evidence. Papers and existing experiment records retain their original dates and status.
